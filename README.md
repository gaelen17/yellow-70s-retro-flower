# 🌸 Retro 70s Vector Flowers

A simple, lightweight experiment featuring retro 70s-style layered vector flowers built with vanilla JavaScript, SVG, and GSAP.

## Features
* **Dynamic SVG Generation**: Built programmatically using JavaScript (`document.createElementNS`) with configurable layers, petal counts, scaling, and rotation offsets.
* **Smooth Animation**: Powered by GSAP for clean entrance transitions and slow, continuous background rotation.
* **Color Variations**: Includes warm solar yellow and soft pastel pink variations sharing the same organic geometry.

## Tech Stack
* HTML5 / SVG
* Vanilla JavaScript (ES6)
* CSS3 (`drop-shadow` filters)
* GSAP (GreenSock Animation Platform)

## Usage
Open the HTML file directly in any modern browser, or drop the code into CodePen.
